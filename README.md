# JavaScript TODO List

A simple and interactive TODO List web application built using HTML, JavaScript, and Bootstrap.

## Features

- Add tasks with a title and description
- View tasks in a table
- Delete tasks when completed or no longer needed
- Save tasks in browser localStorage
- Retain saved tasks after refreshing the page
- Responsive styling with Bootstrap

## Technologies Used

- HTML5
- JavaScript
- Bootstrap 5
- Browser localStorage

## How to Run

1. Download or clone this repository.
2. Open `Todo's List.html` in your web browser.
3. Enter a task title and optional description.
4. Click **Add To List** to add a task.
5. Click **Delete** to remove a task.

## Learning Outcomes

This project demonstrates DOM manipulation, event listeners, arrays, functions, JSON, and browser localStorage.
